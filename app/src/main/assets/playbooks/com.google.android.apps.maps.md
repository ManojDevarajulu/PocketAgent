Use this app for any address or route. Search inside Maps, never in a browser.

1. Open Maps, then tap the search box at the top.
2. If the search box already has text, tap the clear button (the round "x" at the right end of the box) first.
   The box is made of two stacked input fields. If typing does not change the box, clear it and try again
   instead of typing the same text a second time.
3. Type the whole address, then tap the first suggestion in the list, or the search key on the keyboard.
4. When the place opens, tap "Directions", then "Start".
