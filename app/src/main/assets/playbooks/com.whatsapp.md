Use this for chats. To only read or answer a new message, prefer the notification tools first.

1. The chat list shows chats newest first. The search box at the top is labelled "Ask Meta AI or Search".
   Filter chips below it: All, Unread, Favourites, Groups.
2. To open a chat, tap its row (the contact or group name). If it is not visible, tap the search box, type
   the name, then tap the matching chat. Do not tap the Meta AI suggestion.
3. Inside a chat the name is at the top and the message box (an editable field showing "Message") is at the
   bottom. Messages are in a scrollable list; scroll up to read older ones.
4. To reply: tap the message box, type the text, then tap the button labelled "Send". It appears at the right
   of the box only after text is typed; before that the same spot is the "Voice message" button, so never
   tap it.
5. Never press and hold the voice or Attach buttons. Sending always needs the user's yes.
6. Back returns to the chat list. WhatsApp reopens in the last chat, not the list.
